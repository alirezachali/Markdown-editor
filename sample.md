# Markdown Editor

A modern native Markdown editor for Windows with live preview.

## Features

- ✅ **Live preview** with syntax highlighting
- ✅ **File management** — browse and edit `.md` files
- ✅ **Export to HTML**
- ✅ **RTL support** for Persian/Farsi
- ✅ **Dark/Light theme**

## Code Support

```python
def greet(name: str) -> str:
    """Say hello!"""
    return f"Hello, {name}!"

greet("Ali")
```
